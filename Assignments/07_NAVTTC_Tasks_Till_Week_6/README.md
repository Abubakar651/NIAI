## Directory & Curriculum Breakdown

| Week | Directory | Focus & Core Tasks | Task Numbers |
| :--- | :--- | :--- | :---: |
| **Week 1** | [`Week1/`](Week1/) | **Python Basics & Linux**: Installation guide, bash commands, variables, strings, type casting, lists, tuples, dictionaries, sets, conditionals, loops (`for`, `while`, `break`, `continue`, `enumerate`) | Tasks 1–20 |
| **Week 2** | [`Week2/`](Week2/) | **Functions, Exceptions & Stats**: User-defined functions, error handling (`try/except/finally`), custom user exceptions, central tendency (mean, median, mode) & dispersion (variance, std dev) | Tasks 21–23, 49, 50 |
| **Week 3** | [`Week3/`](Week3/) | **NumPy Array Computing**: Creating arrays (0D–3D), indexing, slicing, data types, copy vs view, shape, reshape, iteration (`nditer`), joining (`hstack`/`vstack`), splitting, searching (`where`), sorting, random sampling | Tasks 28–40 |
| **Week 4** | [`Week4/`](Week4/) | **Pandas Data Analysis**: Series, DataFrames, `.loc` selection, CSV ingestion (`data.csv`), data profiling (`describe`, `info`), missing values (`fillna`), deduplication, Pearson correlation matrices | Tasks 41–48 |
| **Week 5** | [`Week5/`](Week5/) | **Classical Machine Learning**: Scikit-Learn `LinearRegression` (train/test split, slope, intercept, MAE, MSE, $R^2$) and `LogisticRegression` (binary classification, confusion matrix, classification report) | Tasks 51–52 |
| **Week 6** | [`Week6/`](Week6/) | **Supervised ML & Time Series**: Decision Tree classification (entropy, max depth), Support Vector Machine (SVC linear kernel), and Pandas Time Series Analysis (rolling average, resampling, datetime indexing) | Tasks 53–55 |
