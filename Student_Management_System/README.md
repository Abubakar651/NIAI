# Student Management System

A Python command-line application that provides student record management using `pandas` and local CSV file storage.

---

## 📌 Features

- **Add Student**: Record student roll number and name with automatic duplicate roll number validation.
- **View Students**: Tabular display of all current student records using pandas formatting.
- **Search Student**: Query and filter records by student roll number.
- **Update Student**: Modify a student's name based on their unique roll number.
- **Delete Student**: Remove a student record and update the persistent CSV storage.

---

## 🚀 How to Run

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Execute the application:**
   ```bash
   python student_management_system.py
   ```
